# Smart Plug Energy-Tracking App 🔌 


## Overview
This project demonstrates an IoT-enabled smart plug designed to monitor and track energy consumption.  
The solution provides real-time usage data and visualizations to help users optimize energy consumption.

## Features
- Real-time energy usage monitoring  
- Historical consumption tracking  
- User-friendly data visualization interface  
- Market strategy analysis for deployment and adoption
